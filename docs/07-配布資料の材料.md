## 2. お客様向けの説明文（そのまま使える）

**一言で**: マイクに向かって話すだけで、会長の予定と「お弁当がいるか」を記録するアプリです。

**何ができるか**
- 予定を話すと、さくらが「こう登録しますね。よろしいですか」と聞き返し、「はい」で所在ダッシュボードに登録されます（訪問・工事・社内・休み）。
- 登録した日のお弁当がいるかいらないかを、さくらが続けて聞きます。「いらない」「お願いします」など普通の言い方で答えられます。
- 「今週の予定は？」「来月は？」「先月は何があった？」と聞くと読み上げます。
- 「さっきの予定は取り消して」で取り消せます。
- 「お弁当」画面で、事務の方が今日・明日・今週の要否を見て注文できます。

**話し方の例**
- 「明日は和俊と菱和産業。朝から行く」
- 「木曜は休み」
- 「来週の月曜から水曜まで、富樫とコマツ大阪に出張」
- 「今日はお弁当いらない」「明日のお弁当はお願いします」

## 3. 使い方（案内 HTML に載せる手順）

**スマホ（Android）**
1. 配布リンクを Chrome で開く（QR を読み取る）。
2. 右上の「⋮」→「ホーム画面に追加」または「アプリをインストール」。アイコン「スケジュール係」がホーム画面に出る。
3. アイコンから開き、緑のマイクボタンを押す。初回だけ「マイクの使用を許可」を押す。
4. さくらが挨拶したら、予定やお弁当のことを話す。終わるときはマイクをもう一度押す。

**PC**
1. 配布リンクを Chrome または Edge で開く。ブックマークしておく。
2. 左に大きくさくらの写真、右にマイクとお弁当ボードが出る。マイクを押して話す。

**注意**
- マイクは https の URL でだけ使える（この公開 URL は対応済み）。
- 1 回の会話は 10 分で自動終了。1 日の音声は合計 60 分まで。
- 会話の内容は保存しない。残るのは登録した予定とお弁当の要否だけ。

## 5. QR とリンク

- QR にするのは配布リンク（`#k=` 付き）そのもの。キーは URL の `#` 以降なのでサーバーのアクセスログには残らない。
- 会長用と管理用でリンクが違う。案内 HTML は「会長のスマホ・PC 用」と「事務用（お弁当ボード確認）」を分けるとよい。
- キーを差し替えたら（`.env` の `APP_ACCESS_KEYS` を更新して `docker compose -f docker-compose.prod.yml --env-file .env up -d api`）、案内 HTML の QR も作り直す。
